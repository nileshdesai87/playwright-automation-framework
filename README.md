# Playwright Automation Framework

QA Automation framework using Playwright (JS) & Selenium (Python) for web and API testing, integrated with CI/CD, parallel execution, and reporting. Designed for SaaS & FinTech applications.

## Features
- Page Object Model (POM) for maintainable UI tests
- API testing using REST & Postman
- Parallel test execution
- CI/CD integration via GitHub Actions
- Retry & flaky test handling
- Docker support

## Tech Stack
Playwright (JS), Selenium (Python), REST APIs, Postman, CI/CD (GitHub Actions), Docker

## How to Run
```bash
git clone https://github.com/username/playwright-automation-framework.git
cd playwright-automation-framework
npm install
npx playwright test
npx playwright show-report
